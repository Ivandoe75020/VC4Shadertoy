# Changelog

Copyright (C) Asger Andersen

## 1.0.0

- Added Shadertoy JSON import and `mainImage` shader conversion.
- Added preview rendering and Buffer A through Buffer D multipass rendering.
- Added ping-pong buffer processing.
- Added image-sequence export pipeline and H.264 MP4 encoding.
- Added 720p and 1080p output at 30 fps and 60 fps.
- Added durations of 60, 90 and 120 seconds.
- Added optional MP3 import and AAC audio encoding.
- Added export cancellation and partial-file cleanup.
- Added Windows light and dark theme support.
- Added SVG interface icons and a multi-resolution executable icon.
- Added FFmpeg LGPL notices and license files.
